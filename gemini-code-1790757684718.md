# Script-Controlled ACL – Restrict Record Access Based on Field Value

## 📌 Project Overview
This project demonstrates how to enforce field-level and record-level security using Scripted Access Control Lists (ACL). It restricts access to specific records based on dynamic field values (e.g., `u_confidential == true`).

## ⚙️ Logic Explanation
- If `u_confidential` field is `true`, only record owners or users with the `admin` role can view/edit.
- If `u_confidential` is `false`, standard read access applies.

## 🚀 How to Test / Demo
1. Import `acl_script.js` into your instance / ACL rules engine.
2. Log in as a regular user -> Observe restricted records are hidden.
3. Log in as an assigned user / admin -> Access is granted.
